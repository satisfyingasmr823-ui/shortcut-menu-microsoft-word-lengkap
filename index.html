Hampir setiap orang pernah membuka Microsoft Word untuk menulis tugas, laporan, surat, atau dokumen kerja. Namun, tidak banyak yang tahu bahwa sebagian besar pekerjaan bisa diselesaikan jauh lebih cepat dengan kombinasi tombol keyboard dan menu yang tepat. Artikel ini merangkum shortcut keyboard untuk meng-copy teks pada Microsoft Word, cara membatalkan perintah, membuat teks tebal, hingga mengatur margin dan jenis kertas, dilengkapi latihan soal dan tips agar semuanya mudah diingat.

Artikel ini ditulis untuk pemula, siswa, mahasiswa, dan siapa pun yang ingin bekerja lebih efisien di depan komputer. Setiap bagian dibuat ringkas, dengan contoh yang bisa langsung Anda coba di dokumen sendiri. Anda tidak perlu menghafal semuanya sekaligus. Cukup pilih beberapa yang paling sering dipakai, lalu tambahkan sedikit demi sedikit.

Mengapa Shortcut Keyboard Penting di Microsoft Word

Setiap kali Anda memindahkan tangan dari keyboard ke mouse untuk mengklik menu, waktu kecil itu terbuang. Jika dikalikan puluhan kali dalam sehari, selisihnya terasa. Shortcut membuat tangan tetap berada di posisi mengetik, sehingga ritme kerja tidak terputus.

Selain menghemat waktu, shortcut juga mengurangi kelelahan. Gerakan berulang pada mouse, terutama saat memilih teks dan membuka menu, bisa membuat pergelangan tangan lebih cepat pegal. Dengan tombol pintas, gerakan itu berkurang.

Shortcut yang baik juga konsisten. Banyak perintah di Word, seperti menebalkan teks atau menyalin, juga bisa dipakai di aplikasi lain seperti peramban dan pengolah angka. Sekali dikuasai, kemampuan ini ikut terbawa ke banyak pekerjaan lain.

Shortcut Dasar: Copy, Paste, Cut, dan Undo

Empat perintah ini adalah fondasi. Hampir setiap pengguna komputer memakainya setiap hari, dan karena itu sebaiknya dihafal terlebih dahulu.

CopySalin teks atau objek dengan Ctrl + C
PasteTempel hasil salinan dengan Ctrl + V
CutPotong teks dengan Ctrl + X
UndoBatalkan perintah terakhir dengan Ctrl + Z

Shortcut untuk shortcut keyboard untuk memotong teks pada Microsoft Word adalah Ctrl + X. Berbeda dengan copy, perintah cut menghapus teks dari posisi awal dan menyimpannya di papan klip, sehingga Anda bisa menempelkannya di tempat lain.

Untuk shortcut keyboard untuk membatalkan perintah yang telah dilakukan sebelumnya pada Microsoft Word, gunakan Ctrl + Z. Jika Anda membatalkan terlalu banyak, tekan Ctrl + Y untuk mengulang perintah yang dibatalkan. Kombinasi ini sangat membantu saat Anda tidak yakin dengan hasil suntingan dan ingin kembali ke kondisi sebelumnya.

Tips cepat: Saat menempel teks dari situs web, Word sering membawa format asalnya. Gunakan Ctrl + Alt + V lalu pilih "Teks Polos" agar dokumen tetap rapi.

Shortcut Format Teks: Tebal, Miring, dan Rata Paragraf

Format teks memberi hierarki pada dokumen. Judul dibuat lebih tebal, kutipan dibuat miring, dan paragraf diratakan agar enak dibaca. Semua itu bisa dilakukan dengan cepat jika Anda hafal kombinasi tombolnya.

Menebalkan dan Memiringkan Teks

Untuk membuat teks tebal pada Microsoft Word, pilih teks lalu tekan Ctrl + B. Untuk membuat tulisan miring, gunakan Ctrl + I. Tombol Ctrl + U digunakan untuk garis bawah. Anda juga bisa menekan kombinasi tombol sebelum mulai mengetik. Teks yang muncul setelahnya akan langsung tebal atau miring, dan tombol yang sama akan mematikan format tersebut.

Beberapa pengguna menanyakan perintah dari keyboard untuk melakukan cetak miring pada tulisan di Microsoft Word. Jawabannya tetap Ctrl + I. Berbeda dengan cetak (print), perintah ini khusus mengubah gaya huruf menjadi miring.

Mengatur Perataan Paragraf

Perataan paragraf menentukan bagaimana teks menempel di tepi halaman. Berikut kombinasinya:

  • Ctrl + L untuk rata kiri.
  • Ctrl + E untuk rata tengah.
  • Ctrl + R untuk rata kanan.
  • Ctrl + J untuk rata kiri dan kanan (justify).

Pertanyaan seperti bagaimana cara membuat teks rata tengah sering muncul di kalangan pemula. Jawabannya cukup pilih paragraf, lalu tekan Ctrl + E. Untuk bagaimana cara membuat teks rata kiri kanan, gunakan Ctrl + J, dan hasilnya akan membuat tepi kiri serta kanan teks sejajar.

Mengatur Jarak Antarbaris

Jarak antarbaris memengaruhi keterbacaan. Dokumen akademik biasanya memakai spasi 1,5 atau 2. Shortcut Ctrl + 1 membuat spasi tunggal, Ctrl + 2 membuat spasi ganda, dan Ctrl + 5 membuat spasi 1,5. Fitur ini termasuk dalam fitur Microsoft Word untuk mengatur jarak teks setiap baris, dan bisa diubah juga lewat menu Paragraf.

Mengubah Ukuran Huruf dengan Cepat

Untuk memperbesar huruf, pilih teks lalu tekan Ctrl + Shift + >. Untuk memperkecil, gunakan Ctrl + Shift + <. Cara ini jauh lebih cepat dibanding membuka kotak ukuran font satu per satu.

Shortcut Dokumen dan File

Selain mengedit teks, Anda juga perlu mengelola dokumen: membuat yang baru, membuka yang lama, menyimpan, dan mencetak. Empat aktivitas ini sebaiknya ikut dikuasai.

Membuka Dokumen Baru

Untuk shortcut keyboard untuk membuka dokumen baru pada Microsoft Word, tekan Ctrl + N. Word akan langsung menampilkan halaman kosong baru tanpa perlu membuka menu File terlebih dahulu. Jika Anda ingin memulai dari templat tertentu, gunakan menu File lalu pilih New.

Membuka File yang Sudah Disimpan

Pertanyaan bagaimana membuka file yang telah disimpan juga sering diajukan. Tekan Ctrl + O untuk membuka jendela pilihan file. Anda juga bisa memilih file dari daftar Dokumen Terakhir yang muncul di layar awal Word.

Menyimpan dan Mencetak

Biasakan menekan Ctrl + S setiap selesai menulis satu bagian. Kebiasaan kecil ini bisa menyelamatkan pekerjaan Anda jika listrik mati atau aplikasi tiba-tiba tertutup. Untuk mencetak, gunakan Ctrl + P, lalu periksa pratinjau sebelum mengirim ke printer.

Pertanyaan bagaimana cara mencetak file dengan keyboard dijawab dengan tombol yang sama. Setelah jendela cetak terbuka, Anda bisa memilih printer, jumlah salinan, dan rentang halaman menggunakan keyboard saja dengan tombol Tab dan panah.

Mencari dan Mengganti Kata

Dokumen panjang sulit dibaca ulang satu per satu. Gunakan Ctrl + F untuk mencari kata, dan Ctrl + H untuk mengganti semua kemunculannya sekaligus. Misalnya, jika Anda salah menulis nama seseorang di 20 tempat, cukup satu kali penggantian.

Menu Penting di Microsoft Word

Tidak semua perintah punya shortcut. Untuk fitur tertentu, Anda perlu tahu menu yang tepat. Word mengelompokkan perintahnya dalam beberapa tab di bagian atas layar, yang disebut ribbon. Berikut tab yang paling sering dipakai.

Tab Beranda (Home)

Tab ini berisi hampir semua alat untuk format dasar. Menu yang digunakan untuk mengatur jenis huruf pada dokumen di Microsoft Word ada di grup Font, tempat Anda memilih jenis huruf, ukuran, warna, dan efek tertentu. Di grup yang sama juga terdapat tombol tebal, miring, dan garis bawah.

Grup Paragraf di tab yang sama mengatur perataan, daftar berpoin, dan menu yang digunakan untuk mengatur spasi antara baris pada dokumen di Microsoft Word. Tombol Line and Paragraph Spacing ada di sini. Jika Anda ingin mengatur jarak lebih detail, buka kotak Paragraf dari panah kecil di sudut grup.

Tab Sisipkan (Insert)

Ketika Anda ingin menambah elemen baru ke dokumen, tab Sisipkan adalah tempatnya. Menu yang digunakan untuk menambahkan gambar pada dokumen di Microsoft Word adalah Insert lalu Pictures. Pilih gambar dari komputer, atau gunakan opsi gambar daring jika tersedia. Setelah gambar masuk, Anda bisa menggesernya dan mengubah ukurannya dengan menarik sudut kotak seleksi.

Untuk menu yang digunakan untuk memasukkan tabel pada dokumen di Microsoft Word, pilih Insert lalu Table. Anda bisa menentukan jumlah baris dan kolom dari kotak kecil yang muncul, atau memilih Insert Table untuk memasukkan ukuran secara manual.

Tab yang sama juga menyediakan hyperlink. Shortcut shortcut keyboard untuk menyisipkan hyperlink pada Microsoft Word adalah Ctrl + K. Blok teks yang ingin dijadikan tautan, tekan kombinasi tersebut, lalu masukkan alamat tujuan.

Tab Tata Letak (Layout)

Tab ini mengatur struktur halaman. Menu yang digunakan untuk mengatur margin pada dokumen di Microsoft Word adalah Layout lalu Margins. Anda bisa memilih margin normal, sempit, atau lebar, atau membuat ukuran sendiri melalui Custom Margins. Margin yang rapi membuat dokumen terlihat profesional, terutama untuk tugas atau surat resmi.

Untuk menu yang digunakan untuk mengatur jenis dan ukuran kertas pada dokumen di Microsoft Word, buka tab Layout lalu pilih Size. Di sini Anda bisa memilih A4, Letter, atau ukuran lain sesuai kebutuhan cetak. Pastikan ukuran kertas sama dengan kertas di printer sebelum mencetak dokumen penting.

Tab Tampilan (View)

Tab ini mengatur cara Anda melihat dokumen. Menu yang digunakan untuk mengatur tampilan halaman pada dokumen di Microsoft Word ada di tab View. Mode Print Layout adalah tampilan paling mirip hasil cetak. Mode Read Mode cocok untuk membaca tanpa menyunting, sedangkan Web Layout berguna bila dokumen akan dipublikasikan di internet.

Anda juga bisa mengatur zoom di tab ini. Jika ingin melihat dua halaman sekaligus, pilih opsi multi-halaman dari grup Zoom.

Catatan: Nama tab bisa sedikit berbeda tergantung versi Word dan bahasa yang digunakan. Jika menu tidak sama persis, cari ikon yang serupa atau gunakan kolom pencarian di bagian atas jendela Word.

Shortcut Tambahan yang Sering Terlupakan

Selain perintah dasar, ada beberapa shortcut yang sangat membantu saat menulis dokumen panjang atau berformat khusus.

Membuat Garis Pemisah

Untuk shortcut garis di Word, ketik tiga tanda hubung --- lalu tekan Enter. Word akan otomatis membuat garis horizontal sepanjang halaman. Jika Anda mengetik tiga tanda garis bawah ___ lalu Enter, hasilnya berupa garis tebal. Cara ini sangat praktis untuk memisahkan bagian dokumen tanpa perlu membuka menu gambar bentuk.

Memberi Warna Latar pada Teks

Word belum memiliki shortcut bawaan untuk shortcut highlight word, jadi fitur ini biasanya dipakai lewat menu. Blok teks, lalu buka tab Beranda dan pilih ikon Text Highlight Color. Pilih warna yang diinginkan. Untuk menghapusnya, pilih opsi No Color. Kebiasaan ini membantu menandai bagian penting saat meninjau ulang dokumen.

Mengubah Huruf Besar dan Kecil

Ada banyak situasi ketika Anda perlu mengubah huruf kapital, misalnya ketika mengetik judul. Shortcut shortcut capitalize each word di Word adalah Shift + F3. Setiap kali ditekan, teks akan berganti antara huruf kapital di awal kalimat, huruf kecil semua, dan huruf kapital semua. Untuk judul dengan huruf kapital di setiap kata, gunakan menu Change Case di tab Beranda agar hasilnya lebih tepat.

Mengetik Lebih Cepat dengan AutoCorrect dan AutoText

Word memiliki fitur yang membantu mengetik lebih cepat dan lebih rapi. Fitur ini mendeteksi kesalahan penulisan dan ejaan, menyisipkan simbol secara cepat, serta melengkapi kalimat hanya dengan mengetik beberapa huruf. Ketiga kemampuan itu dikenal sebagai AutoCorrect dan AutoText. Misalnya, ketik (c) dan Word akan mengubahnya menjadi simbol hak cipta. Anda bisa menambahkan singkatan sendiri melalui File lalu Options, kemudian Proofing dan AutoCorrect Options.

Untuk menyisipkan simbol yang tidak ada di keyboard, gunakan tab Sisipkan lalu Simbol. Simbol yang sering dipakai akan muncul di daftar terakhir, sehingga lebih cepat diambil lain kali.

Shortcut Word yang Lebih Lengkap

Jika Anda sering mencari shortcut Word lengkap, kuncinya adalah mengelompokkannya berdasarkan fungsi. Pertama, perintah untuk dokumen dan file. Kedua, perintah untuk format teks. Ketiga, perintah untuk navigasi, seperti berpindah kata dengan Ctrl + panah kiri atau kanan, dan berpindah ke awal atau akhir dokumen dengan Ctrl + Home atau Ctrl + End. Dengan pengelompokan seperti ini, Anda lebih mudah mengingat dan mencari perintah yang dibutuhkan.

Mengenal Bagian-Bagian Layar Word

Sebelum menguasai menu, kenali dulu bagian layar Word. Hal ini penting agar Anda tidak kebingungan saat membaca panduan atau bertanya kepada orang lain.

  • Title bar: bagian paling atas jendela yang menampilkan nama file dan tombol minimize, maximize, serta close. Inilah yang dimaksud dengan elemen paling atas pada Word.
  • Quick Access Toolbar: deretan ikon kecil di pojok kiri atas untuk perintah yang sering dipakai, seperti simpan dan batalkan. Anda bisa menambahkan perintah sendiri lewat panah kecil di sebelahnya.
  • Ribbon: area berisi tab seperti Beranda, Sisipkan, Tata Letak, dan Tampilan.
  • Area dokumen: tempat Anda menulis dan menyusun halaman.
  • Status bar: bagian bawah yang menampilkan jumlah halaman, jumlah kata, dan pengaturan zoom.

Jika ribbon terasa memakan tempat, Anda bisa menyembunyikannya dengan menekan Ctrl + F1. Tekan kembali untuk menampilkannya lagi.

Shortcut di Browser dan Windows yang Berkaitan dengan Dokumen

Pekerjaan dokumen sering berhubungan dengan internet, mulai dari riset hingga mengunduh materi. Beberapa shortcut di peramban dan Windows membantu alur kerja tersebut.

Mode Penyamaran

Mode penyamaran, atau Incognito di Chrome dan InPrivate di Edge, membuat peramban tidak menyimpan riwayat penelusuran, cookie, dan data formulir setelah jendela ditutup. Untuk membukanya, gunakan Ctrl + Shift + N. Fitur ini berguna saat Anda memakai komputer bersama atau mencari referensi di perangkat pinjaman. Perlu diingat, mode ini tidak membuat aktivitas Anda tidak terlihat oleh penyedia internet atau administrator jaringan.

Pertanyaan seperti shortcut fitur incognito adalah dijawab dengan kombinasi tersebut. Pada peramban yang berbeda, nama fitur bisa berbeda, tetapi kombinasinya umumnya sama.

Menyimpan Halaman Web agar Bisa Dibaca Offline

Jika Anda ingin membaca artikel saat tidak ada koneksi, simpan halamannya terlebih dahulu. Menyimpan artikel pada sebuah website menjadi offline dapat menggunakan shortcut Ctrl + S di peramban. Pilih lokasi penyimpanan, lalu pilih format halaman web lengkap agar gambar ikut tersimpan.

Membuka File yang Sudah Diunduh

Jika Anda baru saja mengunduh materi, buka daftar unduhan dengan Ctrl + J di Chrome atau Edge. Dari sana Anda bisa langsung membuka file yang sudah diunduh. Ini termasuk jawaban untuk shortcut yang digunakan untuk membuka file yang telah diunduh pada web browser.

Peramban Bawaan Windows

Pertanyaan web browser yang disediakan oleh sistem operasi Windows sering muncul di kelas komputer. Jawaban yang tepat untuk Windows modern adalah Microsoft Edge, yang sudah terpasang sejak awal. Meski begitu, pengguna tetap bebas memasang peramban lain seperti Chrome atau Firefox.

Menyematkan Aplikasi ke Taskbar

Fitur pin to taskbar digunakan untuk menampilkan pintasan aplikasi pada taskbar, yaitu bilah di bagian bawah layar. Klik kanan ikon aplikasi, lalu pilih Pin to taskbar. Dengan begitu, Microsoft Word bisa dibuka hanya dengan satu klik kapan saja.

Membuka Program Office dengan Cepat

Untuk membuka program Microsoft Office dengan menu shortcut secara cepat, gunakan alat bantu pencarian Windows atau kotak Run. Tekan Windows + R, ketik nama program seperti winword, lalu Enter. Cara lain adalah menekan tombol Windows, mengetik "Word", lalu memilih hasilnya dengan tombol panah dan Enter.

Mengenal CMS dan Perbedaannya dengan Pengolah Kata

Dalam dunia internet, sering muncul istilah CMS atau Content Management System. CMS adalah perangkat lunak untuk membuat dan mengelola konten situs web tanpa harus menulis kode dari nol. Contoh yang populer antara lain WordPress, Joomla, dan Drupal. Blogger juga termasuk dalam kategori ini.

Pertanyaan berikut merupakan contoh CMS kecuali bisa dijawab dengan mudah jika Anda memahami fungsinya. Microsoft Word bukan CMS, karena Word adalah pengolah kata untuk membuat dokumen cetak atau file digital, bukan untuk mengelola situs web secara langsung. Perbedaan ini penting agar Anda tahu alat mana yang tepat untuk setiap pekerjaan.

Tips Menghafal Shortcut Tanpa Stres

Menghafal puluhan kombinasi tombol sekaligus hampir pasti gagal. Cara yang lebih efektif adalah belajar sedikit demi sedikit, dengan pola yang mudah diulang.

Mulai dari Lima Shortcut Paling Sering

Pilih lima perintah yang paling sering Anda gunakan, misalnya copy, paste, undo, simpan, dan tebal. Pakai selama satu minggu tanpa melirik menu. Setelah terbiasa, tambahkan lima lagi.

Kelompokkan Berdasarkan Fungsi

Otak lebih mudah mengingat hal yang berhubungan. Kelompokkan shortcut menjadi tiga: untuk teks (tebal, miring, garis bawah), untuk paragraf (rata kiri, tengah, kanan), dan untuk dokumen (baru, buka, simpan, cetak).

Tempel Daftar di Dekat Layar

Cetak satu halaman daftar shortcut dan tempelkan di dekat monitor. Melihatnya berulang kali akan membuat kombinasi itu menempel dengan sendirinya.

Gunakan dalam Pekerjaan Nyata

Cara terbaik untuk mengingat adalah menggunakannya saat bekerja. Cobalah mengetik tugas Anda tanpa mouse selama satu sesi. Awalnya lambat, tetapi dalam beberapa hari Anda akan merasakan perbedaannya.

Kesalahan Umum Pemula

Ada beberapa kebiasaan yang sering memperlambat pekerjaan di Word. Pertama, memformat teks satu per satu padahal bisa dipilih sekaligus. Kedua, menekan Enter berkali-kali untuk membuat jarak, padahal jarak antarparagraf bisa diatur dari menu. Ketiga, mengetik spasi ganda untuk merapikan kalimat. Keempat, menyimpan dokumen hanya di akhir pekerjaan. Kelima, menempel teks dari internet tanpa membersihkan formatnya, sehingga dokumen berantakan.

Menghindari kebiasaan ini saja sudah membuat dokumen lebih rapi dan pekerjaan lebih cepat selesai.

Pertanyaan yang Sering Diajukan

Apakah shortcut Word bisa dipakai di Mac?

Sebagian besar kombinasi memakai tombol Command sebagai pengganti Ctrl. Beberapa perintah bisa berbeda, jadi periksa menu Help pada aplikasi Anda.

Mengapa shortcut saya tidak berfungsi?

Pastikan tidak ada kursor yang sedang aktif di kotak lain, seperti kolom judul atau kotak dialog. Jika masih gagal, periksa apakah keyboard Anda memakai tombol Fn yang perlu ditekan bersamaan untuk tombol angka tertentu.

Apakah menu di setiap versi Word sama?

Tidak selalu. Versi terbaru bisa memiliki nama tab atau ikon yang sedikit berbeda. Namun, shortcut dasar seperti Ctrl + C, Ctrl + V, dan Ctrl + Z hampir selalu sama di semua versi.

Kesimpulan

Menguasai shortcut dan menu Microsoft Word bukan soal menghafal semuanya sekaligus. Mulailah dari perintah dasar seperti copy, paste, undo, dan simpan, lalu tambahkan format teks, pengaturan halaman, dan fitur lanjutan secara bertahap. Dengan latihan kecil setiap hari, dokumen Anda akan lebih rapi, pekerjaan lebih cepat selesai, dan tangan tidak mudah lelah.
